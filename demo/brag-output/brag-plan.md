# Bunshin — Copying finished. But did it match?

Brag full workflow, polished tone, landscape 1920×1080, exactly 25 seconds,
30 fps. Voice off. Actual WPF acceptance screenshots, edited into a product
tour rather than presented as a recording of transfer speed.

## Nine-question rubric

1. Windows copy utility with per-file SHA-256 verification.
2. Strongest grounded claim: “Your copy is verified.”
3. Visual hook: twin-sheet cobalt mark and the persistent green verdict.
4. Real ready, resolved-target, hashing and successful-result screens.
5. User explicitly requested 25 seconds; five beats allow readable holds.
6. Polished / quiet precision, matching the actual light interface.
7. Restrained music bed, three soft placement accents; no narration.
8. Bunshin copies files, checks their contents, and shows whether they match.
9. Add sources → review destination → copy and hash → read the verdict.
